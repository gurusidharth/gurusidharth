- Mobile application development using **React Native**, shipping cross-platform apps used by real customers
- Backend engineering focused on **REST API design**, authentication/authorization, and service-oriented architecture
- Data layer experience across **MongoDB** and **MySQL**, with schema design driven by access patterns and scale
- Working knowledge of **cloud technologies** (AWS) and modern **CI/CD** practices for reliable, repeatable deployments

I care about writing software that is scalable, maintainable, and built to survive contact with production — not just code that works on my machine.

|---|---|

| **Challenges** | Keeping the UI responsive while awaiting variable-latency AI responses |

### Football Live Score Platform

| | |

| **Technologies** | React, Node.js, REST APIs, MySQL |

| **Challenges** | Delivering near real-time updates without overloading the backend with excessive client requests |
